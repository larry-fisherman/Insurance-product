# Roadmap status at engineering review

This maps the original plan to the delivered synthetic build. [Review remediation](review-remediation.md) is the current detailed record of defect fixes and outstanding functional gaps; the table below is not a statement that all engineering phases are complete. “Implemented” describes software in the repository; it does not replace the phase acceptance conditions that require customer, domain, legal, or external infrastructure evidence.

| Plan phase                    | Engineering delivery                                                                                                             | Remaining validation / release work                                                                                                    |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 0: discovery and architecture | plan.md, architecture decisions, concrete scope, release gates                                                                   | Broker interviews, licensed CGL adjudication, workflow/pricing and template-rights validation                                          |
| 1: foundation                 | Monorepo, Docker, CI, PostgreSQL migrations, roles, forced RLS, password/TOTP sessions and permissions                           | Production managed identity, verified email ownership, cloud/TLS/IAM and independent boundary assessment                               |
| 2: accounts/workspaces        | Agency onboarding, insureds, submissions/renewals, responsibility/dates, invitations/roles                                       | Broker onboarding and representative operational requirements                                                                          |
| 3: document intake            | Private storage, quarantine/ClamAV, native/OCR PDF, bounded XLSX, jobs/outbox/retries, source locations                          | Production S3/versioning/encryption and hostile-file corpus assessment                                                                 |
| 4: extraction/evidence        | Local parser; optional structured gateway/OpenAI adapters; validation and source checks; 100 generated regression packets        | Approved live provider terms/account/model and independent held-out insurance corpus; complex schedule handling                        |
| 5: reconciliation             | Context-aware amount/name/date conflicts, missing requirements, duplicate claims, no-loss contradictions and explicit exceptions | Licensed reviewer validation of rule applicability/materiality and accuracy targets                                                    |
| 6: human review               | Approve/correct/reject/omit/attest, immutable decisions and snapshots, row/evidence versions                                     | Pilot usability, correction burden, enterprise approval policy                                                                         |
| 7: packages/export            | Original PDF/XLSX/ZIP, narrative from reviewed facts, citation index, sealed manifest, approval and unchanged-byte export        | Broker/carrier acceptance of actual formats and independent unsupported-statement audit                                                |
| 8: pilot gate                 | Unit/component/database/browser checks, synthetic evaluation, scan/OCR checks, local backup/restore tooling, runbooks            | Actual customer-data authorization, independent security review, held-out domain evaluation, production recovery and incident sign-off |
| 9: pilot/commercialization    | Measurement inputs and usage records, documented pricing/rollout hypotheses and future integration boundaries                    | Real pilots, pricing/support/contracts/E&O, unit economics and broader commercial launch                                               |

The review build intentionally remains synthetic-only. Roadmap integrations, additional insurance lines, coverage/quote analysis, automated external distribution, client portals, and billing are not presented as implemented. See pilot-readiness.md for the exact outstanding gates.
